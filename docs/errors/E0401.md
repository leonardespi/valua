# E0401 — Post-Lua-5.5 source feature

## Description

The source file contains a construct that belongs to a Lua version newer than 5.5. valua's source language is Lua 5.5 (with Lua 5.4 as a fully supported subset). Any syntax or semantic feature introduced in a hypothetical Lua 5.6+ is outside the defined source domain.

## Triggering example

This error is reserved for future use. The specific trigger depends on the Lua 5.6+ feature in question.

## Justification

The source language boundary is fixed at Lua 5.5 for valua 1.0. Accepting post-5.5 features would require parser and semantic changes that are out of scope. See PRD §14.2 (Pivot A — Lua 5.6+ source support).

## Remediation

- Downgrade the source construct to a Lua 5.5-compatible equivalent.
- If you need Lua 5.6+ source support, file an issue with a concrete use case. valua is architecturally ready to add new transformer passes for new source versions, but will not do so without demand signals.
